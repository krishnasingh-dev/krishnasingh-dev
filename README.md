## 👨‍💻 About Me

I'm **Krishna Singh**, a Java Backend Developer Intern and BCA student passionate about building reliable, scalable, and maintainable backend applications. I have hands-on development experience with **Java, Spring Boot, RESTful APIs, Hibernate, Spring Data JPA, MySQL, and JWT Authentication**. Through my internship, I'm gaining practical experience in backend development, database operations, API integration, and understanding real-world application architecture. I enjoy writing clean code, solving engineering problems, and continuously improving my development skills. Currently, I'm exploring **Microservices, Redis, Docker, and Apache Kafka** to strengthen my knowledge of modern backend engineering and distributed systems.
